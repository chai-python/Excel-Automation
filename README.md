# Excel-Automation

## 1. プロジェクト概要

Pythonを用いて、Excel形式の業務データの集計・品質チェック・レポート作成を自動化するツールを開発する。

## 2. 開発背景・目的

Excelを用いた業務では、複数のファイルのデータを手作業で集計したり、入力ミスや欠損値を確認したりする作業が発生する。
本プロジェクトでは、これらの作業をPythonで自動化することで、作業時間の短縮とデータの正確性向上を目指す。

## 3. 実装予定の機能

- Excelファイルの読み込み
- 複数のExcelファイルの一括読み込み・データ統合
- 売上データの集計・分析
- 欠損値や異常データのチェック
- 集計結果をまとめたExcelレポートの自動生成

## 4. 使用技術

- Python 3.12
- pandas
- openpyxl（導入予定）
- Git / GitHub
