# Excel-Automation

## 1. プロジェクト概要

Pythonを用いて、Excel形式の業務データの集計・品質チェック・レポート作成を自動化するツールを開発する。

## 2. 開発背景・目的

Excelを用いた業務では、複数のファイルのデータを手作業で集計したり、入力ミスや欠損値を確認したりする作業が発生する。
本プロジェクトでは、これらの作業をPythonで自動化することで、作業時間の短縮とデータの正確性向上を目指す。

## 3. 機能

### 実装済みの機能

- 複数のExcelファイルの一括読み込み・データ統合
- Excel一時ファイルの除外
- ファイル読み込み時の例外処理
- 必須列の存在チェック
- 数値型チェック・欠損値チェック
- 数量・単価の異常値チェック
- 正常データ・異常データ・返品候補データの分類
- 複数の異常理由の記録
- 元ファイル名の記録
- 正常データを対象とした商品別売上・総売上金額の集計

なお、数量が負数であり、その他の異常がないデータは返品候補として分類する。実際の返品であるかどうかは元データのみでは判断できないため、正常売上の集計対象から除外し、確認用のデータとして保持する。

### 今後実装予定の機能

- Excelレポートの自動生成
- 売上集計・異常データ・返品候補データ・処理サマリーの出力
- レポートの書式設定・グラフの作成
- コードの関数化・構造改善
- テストの拡充とエラー処理の改善

## 4. 使用技術

- Python 3.12
- pandas
- openpyxl
- Git / GitHub

## 5. 開発状況

現在は、複数のExcelファイルの統合、売上集計、基本的なデータ品質チェックおよび異常理由の記録機能を実装済みである。
正常データ、欠損値、数値変換エラー、複数の異常を含むデータ、返品候補データ、破損ファイルを用いた手動テストを実施した。
今後はExcelレポートの自動生成機能を実装し、コードの保守性と処理の信頼性を高めていく。
